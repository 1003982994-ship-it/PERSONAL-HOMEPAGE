# 高校教师个人工作台

一个基于 React + Vite + TypeScript 的本地网页应用，用于记录上课、开会、监考、行政事项、灵感、待办事项和事项进展。

## 运行

```bash
npm install
npm run dev
```

## 当前功能

- 新增、编辑、删除、标记完成记录
- 使用 localStorage 自动保存数据
- 自动根据日期计算校历周次
- 工作台首页、日历视图、周视图、记录列表、灵感库、新增记录、设置页
- 新增和编辑记录使用独立页面，浏览页面保持清爽
- 周视图支持按校历周查看事项，并保存本周总结
- 按日期、周次、类型、状态筛选
- 关键词搜索
- JSON 导出与导入恢复，包含记录和周总结
