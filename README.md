# 高校教师个人工作台

一个基于 React + Vite + TypeScript 的本地网页应用，用于记录上课、开会、监考、行政事项、灵感、待办事项和事项进展。

## 运行

```bash
npm install
npm run dev
```

## 本地记录与线上展示

本应用分为两种使用方式：

- 本地页面（`localhost` / `127.0.0.1`）：正式记录入口，数据保存在本机浏览器 localStorage。
- 线上页面：只读展示页，读取随项目发布的 `public/workbench-data.json` 快照。

不需要 Vercel Redis/KV，也不需要同步口令。

### 发布线上展示快照

1. 在本地页面完成记录。
2. 进入“设置”，点击“导出备份 JSON”，保存到桌面或桌面的子文件夹。
3. 在项目目录运行：

```bash
npm run snapshot:sync
```

4. 脚本会自动扫描桌面及子文件夹中最新的 `teacher-workbench-*.json`，并替换 `public/workbench-data.json`。
5. 提交并推送到 GitHub，Vercel 重新部署后，线上页面会展示这份快照。

线上页面不会新增、编辑、删除记录；它只展示发布时的快照。

如果导出文件放在其他文件夹，可以直接运行脚本并指定路径：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\sync-snapshot.ps1 -SourceDir "D:\你的文件夹"
```

## 当前功能

- 新增、编辑、删除、标记完成记录
- 使用 localStorage 自动保存数据
- 自动根据日期计算校历周次
- 工作台首页、日历视图、周视图、记录列表、灵感库、新增记录、设置页
- 新增和编辑记录使用独立页面，浏览页面保持清爽
- 周视图支持按校历周查看事项，并保存本周总结
- 按日期、周次、类型、状态筛选
- 关键词搜索
- JSON 导出与导入恢复，包含记录和周总结
