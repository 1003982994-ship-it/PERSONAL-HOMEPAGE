# 高校教师个人工作台

一个基于 React + Vite + TypeScript 的本地网页应用，用于记录上课、开会、监考、行政事项、灵感、待办事项和事项进展。

## 运行

```bash
npm install
npm run dev
```

## 本地与线上数据同步

本应用会在浏览器 localStorage 中保留一份缓存。部署到 Vercel 后，如果项目配置了 Redis/KV 环境变量，线上网页会通过 `/api/workbench` 自动保存和读取云端记录。

### 配置 Vercel 云端保存

1. 在 Vercel 项目中添加 Redis/KV 存储集成，让项目获得 `KV_REST_API_URL` 和 `KV_REST_API_TOKEN` 环境变量。
2. 建议再添加一个 `WORKBENCH_SYNC_TOKEN` 环境变量，作为同步口令。
3. 重新部署项目。
4. 打开线上页面，在“设置”的“同步口令”里填写同一个口令。

### 把本地数据搬到线上

1. 打开有旧数据的不联网/本地页面。
2. 进入“设置”，点击“导出备份 JSON”。
3. 打开联网页面。
4. 如果设置了同步口令，先在“设置”里填写口令，确认“云端同步”连接正常。
5. 点击“导入备份 JSON”，选择刚才导出的文件。

导入会替换当前页面中的记录和周总结，并自动保存到云端。导入前如果线上已有新内容，建议先在联网页面也导出一份备份。

## 当前功能

- 新增、编辑、删除、标记完成记录
- 使用 localStorage 自动保存数据
- 自动根据日期计算校历周次
- 工作台首页、日历视图、周视图、记录列表、灵感库、新增记录、设置页
- 新增和编辑记录使用独立页面，浏览页面保持清爽
- 周视图支持按校历周查看事项，并保存本周总结
- 按日期、周次、类型、状态筛选
- 关键词搜索
- JSON 导出与导入恢复，包含记录和周总结
